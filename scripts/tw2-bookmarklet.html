TW2 Route Extractor

Extracts all TW2 route GUIDs for Durham and Yorkshire. Run on TW2 map page while logged in.

Instructions

  1. Drag the green button above to your bookmarks bar
  2. Go to TW2 map (logged in)
  3. Click the bookmarklet
  4. Wait for it to finish (shows progress)
  5. It downloads tw2-routes.json
  6. Move that file to src/data/tw2-routes.json in this project
  7. Run: node scripts/build-tw2-mapping.mjs
  8. Rebuild the app: npm run build

After that, every matched route in our app will have a direct "View on TW2" link opening the exact route detail page with comments.
