TW2 Route Extractor

This bookmarklet runs on the TW2 map page to extract route GUIDs for our Green Lanes app.

Setup

  1. Drag this link to your bookmarks bar:

📥 Extract TW2 Routes

Usage

  1. Log into TW2
  2. Once on the map page, click the bookmarklet in your bookmarks bar
  3. It will download a tw2-routes.json file
  4. Place that file in the project at src/data/tw2-routes.json
  5. Run: node scripts/build-tw2-mapping.mjs to generate the mapping

What it does

The bookmarklet queries TW2's WFS API (from their own domain, using your logged-in session) to fetch all BOAT and UCR routes in the Durham/Yorkshire area. It downloads a JSON file with route GUIDs that we can match to our OSM data.

Privacy

The data stays on your machine. Nothing is sent to any third party. The bookmarklet only talks to trailwise2.co.uk.
